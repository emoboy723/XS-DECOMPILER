# Contribuir

Abre un issue describiendo el problema o mejora antes de cambios grandes. Usa Python 3.13 en Windows, instala `requirements-dev.txt` y ejecuta las pruebas del README. Incluye pasos para reproducir, evidencia y límites de la validación. Añade pruebas relevantes cuando cambie el comportamiento. Conserva los originales y el consentimiento antes del envío a IA.

No subas claves, datos de `data/`, muestras privadas, resultados de terceros ni herramientas comerciales. Usa fixtures propios y pequeños. Mantén las licencias de dependencias. Las contribuciones de código propio se publican bajo MIT.
